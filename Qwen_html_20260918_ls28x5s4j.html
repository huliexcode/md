01

الرموز ومواضعها

قراءة getTextContent مع التحويل المصفوفي لكل رمز: النقطة (x,y)، الارتفاع، اسم الخط، وعرض التقدم.

02

تجزئة الأعمدة

مخطط إشغال أفقي يكشف الفراغات الكبيرة ويقسّم الصفحة إلى عمودين أو ثلاثة قبل القراءة.

03

الأسطر والاتجاه

تجميع الرموز بمركز رأسّي متقارب، ثم ترتيبها بصرًًا حسب اتجاه النص: عربي يمين→يسار، لاتيني العكس.

04

التصنيف

حجم الخط مقابل وسيط المستند ⇒ عنوان H1-H6. البادئات ⇒ قوائم. محاذاة الأعمدة الثابتة ⇒ جداول. أحادي المسافة ⇒ كود.

05

التصدير والربط

Markdown + شجرة أقسام JSON + نتائج قواعد الاستخراج، تُدفَع لنقطتك أو تُجلب منها.

مكتبة المستندات

نسخ محفوظة محليًا بمعرّف ثابت، لتعود إليها أو تُعيد دفعها دون إعادة التحويل.
